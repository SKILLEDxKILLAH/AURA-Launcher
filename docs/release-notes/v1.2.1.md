## AURA 1.2.1

AURA's app ID is now **`com.auralab.launcher`**, because `com.aura.launcher` was already taken on Google Play. Nothing else changed.

**If you had an earlier version installed:** Android treats this as a new app, so it installs next to the old one instead of replacing it.
1. Install 1.2.1, then press Home and choose the new **AURA** (or go to Settings → Set AURA as your home app).
2. Set Gemini up again. Choosing **On this phone** or a **free Gemini key** takes a minute.
3. Uninstall the old AURA.

Your settings, favorites and widgets don't carry over from the old app.

**Using "Continue with Google"?** Add another Android client in Google Cloud with the package name `com.auralab.launcher` and the same SHA-1. See docs/GEMINI_SETUP.md.
